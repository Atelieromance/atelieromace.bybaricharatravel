# Atelier Romance

Sitio estatico. Subir el contenido de esta carpeta a la raiz del repo de GitHub Pages.

- `index.html` — puerta de entrada (Novios / Wedding Planner)
- `novios.html` — experiencia de novios + cuestionario
- `planners.html` — Atelier Romance Pro (planners)
- `support.js` — runtime (necesario)
- `assets/` — fotos, stickers, favicon
- `.nojekyll` — evita que GitHub Pages procese los archivos
